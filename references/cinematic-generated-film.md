# 电影感生成短片

用于用视频生成工具逐镜制作 1～10 分钟、追求「大片感」的叙事短片：奇幻动画、无对白绘本改编、风景史诗或情绪短片。本页负责故事蓝本、全片制作顺序和画面语言；选定了某种整体风格时再读对应风格包，目前有 [日式手绘奇幻电影](hand-drawn-fantasy-style.md)；声音由谁生成见 [视听设计 · 原生声音与后期分工](generated-audiovisual.md#原生声音与后期分工)；具体发给 Muse 的结构化提示词见 [镜头请求模板](shot-request-template.md)。对白剧、口播、产品宣传不读本页。

## 1. 先认清单位：一条原片 ≈ 一个镜头

当前常见的生成入口单段约 10 秒，长片靠逐镜生成后剪辑；以实际入口的实测为准。一条生成片段通常是一个连续机位，从中剪两刀得到的是同机位跳切，不是两个镜头。电影节奏的剪辑镜头多在 3～8 秒，所以：

- 成片镜头数 ≈ 成片秒数 ÷ 平均镜长；4 分钟、平均 5～6 秒约需 40～45 个镜头，也就是约 40～45 条可用原片。
- 生成次数 = 可用原片 ÷ 实际返回率 + 返修；先用前几条实测返回率，不照抄他人数字。
- 每条原片取动作完整、首尾稳定的一段，入出点各留余量。

## 2. 故事蓝本：改编优先于凭空原创

成熟绘本、童话和民间故事经过长期打磨，情节骨架与意象通常比模型即兴编出来的强。挑选或改编时检查：

| 检查项 | 为什么 |
|---|---|
| 版权：作者去世满 70 年或明确公有领域；在世作者的作品只学手法 | 改编要能公开发布 |
| 拍点能用肢体与画面讲清，不靠台词 | 无对白片完全依赖可见动作；生成工具的对白与画面文字也最不可靠 |
| 世界统一、人物少 | 每多一个反复出现的角色，跨镜一致性风险就增加一层；群像最难 |
| 至少 3 个能做成「大景揭示」的时刻 | 大片感主要来自几次空间揭示，而不是镜头数量 |
| 有一个可贯穿全片的道具或强调色 | 让入口、转折与归途有视觉回扣，也方便匹配剪辑 |
| 与知名作品的撞型点 | 结构相似难免；入口物件、世界规则、标志性意象与结尾镜头要换掉 |

改编幅度分阶段：初期保留原作骨架，只调人物造型、删去恐怖或说教段落、补足视觉奇观；成熟后再只借结构大改。改编结果写入制作说明（蓝本出处、版权依据、保留与改动），后续所有镜头以它为准。

## 3. 制作顺序：每道关卡过了才花下一笔额度

1. **视觉圣经**：角色定妆、关键场景、色彩脚本（每段主色与光）各一张左右，作者认可后锁定风格句与角色锚点句。
2. **剧情因果审查**（镜头表写完、生成首帧之前）：让一个没看过创作过程的审稿者（新开的子 Agent 或作者）只读镜头表，逐镜复述「观众此刻看到什么、知道什么」，并检查下面四项。发现缺口就补镜头或改动作，不靠旁白和字幕解释。
   - **状态变化有镜头**：人物从 A 处到了 B 处、东西从有到没有、从白天到夜晚，中间必须有观众看得见的过程镜头。
   - **世界跨越要拍出来**：掉进井里、走进门里、飞上云端这类穿越，至少要有「临界动作 → 穿越过程 → 落地或抵达」三拍。只有起点和终点，观众会看不懂发生了什么。
   - **道具按常理运动**：东西掉落、被风吹走、被人拿走都要有可见的原因。不写「线头跳进井里」这种自己会动的动作，除非这个世界有明确的魔法规则，而且已经交代过。
   - **每镜写明人数**：哪些角色在画面里、各几个。拉远、俯瞰和群景最容易把同一个角色复制成好几个。
3. **静图动态分镜（animatic）**：每镜一张首帧静图，按目标时长排进时间线，配临时音乐或无声，产出与成片等长的静图版。**这是批量生成视频前的硬关卡**：作者看完静图版、确认故事看得懂、节奏成立之后，才批量生成视频。改故事在这一步几乎不花视频额度；跳过它，剧情问题要到粗剪才暴露，那时已经花掉全部额度。
4. **画风关卡：看动态，不只看静图**：静图上认可的画风，动起来以后观感可能差很多，比如人物表情和动作的味道、色彩在运动中的变化。先连续生成同一段落的 3～5 镜，剪成 20～30 秒小样，配上临时配乐，请作者判断「像不像目标风格」。不像就换方向重做小样，比如换参考图、换风格句、换画风描述的侧重；连续 2～3 个方向都不像时，停下来和作者讨论换工具或改风格目标，不进入批量生成。
5. **代表镜试片**：先生成最不确定的几镜（大景揭示、特写一致性、声音写法），校准实测分辨率、时长、返回率与声音质量，再批量生成。可以和第 4 步的小样合并。
6. **逐镜生成与选片**：按段落成批生成，每批先审再进下一批；依赖前镜末态的镜头排在前镜确认之后。
7. **粗剪 → 配乐 → 精剪 → 连续看听验收**：声音按 [原生声音与后期分工](generated-audiovisual.md#原生声音与后期分工) 处理，环境声与拟音原生，配乐整片单独做；改了剪点就重查相关接缝和音乐。

作者参与的节点是视觉圣经、静图版、画风小样与粗剪；中间常规生成与选片由 Agent 完成，不逐镜请示。这是新方向、逐镜生成这类高成本短片的档位；其他任务的确认节点按[制作流程 §1](production.md#前期与作者共同定方向)分档。

## 4. 画面语言：电影感从哪里来

### 大景与尺度

- 人物只占画面很小一部分（约 1～5%），用熟悉的人体尺寸衬出空间。
- 每帧都有前、中、后三层：前景虚化的叶片、门框或栏杆，中景主体，远景山海云；远景用空气透视（更淡、更偏冷）拉开距离。
- 环境自己在动：云影扫过草坡、风过草浪、水面碎光、炊烟、飞鸟。环境层的微动比角色大动作更能让画面「活」。
- 大景至少停留 6～8 秒，让观众看清空间，配乐在这里起势。

### 揭示镜头（全片的「大片时刻」）

每个段落安排一个，全片 3～5 个即可，多了就不稀罕：

- **拉出揭示**：从手、道具或脸的特写缓慢拉开到全景。
- **仰摇揭示**：从地面或人物背影缓慢上摇到天空或巨构。
- **遮挡揭示**：从门框、井口、树洞或云层后推出去，豁然开朗。
- **俯瞰揭示**：跟随一个飘落物（羽毛、花瓣、雪）下降，最后俯瞰整片大地。

揭示镜头单独做首帧并优先试片，它们决定全片的上限。

### 运镜

- 每个运镜都要有动机：推近用于情绪靠近，拉远用于揭示或告别，横移配前景视差用于展示空间，跟随用于旅程；安静或幽默的时刻用固定机位。
- 速度慢而稳；一镜一个主要运镜路径，不把推、拉、摇、旋转、穿越都塞进一镜。复杂动作放在镜头前半段，后半段留给完成和稳定。
- 少用快速运动、快速摇镜和高速追逐：生成模型在快速运动上的物理准确性普遍较弱，会出现拉丝和变形。需要速度感时，用前景掠过、风和布料来表现。

### 转场

- 默认直切。好的直切靠动作、视线或声音衔接，不靠特效。
- **形状/运动匹配**：上一镜的圆形井口切到下一镜的月亮，飘落的羽毛切到雪花。在镜头卡里写明上一镜的出点构图和下一镜的入点构图。
- **白光/亮场淡化**：用于穿越入口、梦境进出。
- **声音桥**：下一场的风声或水声提前半拍进入，再切画面。
- 叠化只用于时间流逝，不用来遮掩空间错位或生成瑕疵。

### 景别节奏与段落结构

- 全景、中景、特写、局部细节交替；不能全程广角，也不能全程特写。
- 触感特写（手接住雪、拧干的布、敲门的小手）建立真实感，是大景之间的呼吸。
- 段落按情绪写成色彩脚本：如「日常（暖灰）→ 穿越（白光）→ 奇境（高饱和蓝绿）→ 高潮（金色逆光）→ 归途（冷白雪光）」。
- 高潮前放慢，给最大的揭示镜头留时间；结尾回到开场的地点或道具，形成回扣。

### 画风一致性（生成动画最常见的失败）

- 风格句和角色锚点句每镜逐字复用（写法见 [镜头请求模板](shot-request-template.md)）。
- 特写最容易漂：同一条片子里，全景是水彩质感，切到特写却变成另一种线条与五官，发型和配饰也跟着变。特写镜单独检查，必要时用该角色已认可的特写作为身份参考。
- 用 2 个以上不可混淆的服装/发饰锚点识别角色（如红发绳加蓝背带裤），不靠「同一个女孩」这类描述。
- 画面里不要出现需要识读的文字、招牌和商标：生成文字常是伪字。
- 风格默认用可描述的视觉属性表达（水彩质感背景、干净的赛璐璐人物线条、有方向的自然光、低饱和加单一强调色），不直接复用知名作品的标志性意象；是否在请求里点名某种流派或作者，按风格包的说明在试片中对照决定。

## 5. 验收

在 [制作流程 · 检查和交付](production.md#5-检查和交付) 之外，本类片额外检查：

- 每镜抽帧数人数：同一角色有没有被复制成两个以上，有没有多出来的人，尤其是拉远、俯瞰和群景镜头。
- 按剧情顺序连续看一遍，确认每个因果和每次世界跨越都有对应的镜头，道具的去向前后对得上。

- 每个揭示镜头是否真的「打开」了空间，停留时间够不够看清。
- 连续播放每个接缝：主体大小、运动方向、光向和色温是否连贯；特写与全景的风格、角色是否一致。
- 整片色彩脚本是否按段落推进，有没有某段突然变成另一种画风。
- 无对白片关掉声音看一遍，确认故事仍能看懂；再只听声音不看画面一遍，确认声音段落有起伏、接缝不突兀。
