# 电影感生成短片（选材、大景尺度与揭示设计）

用于用视频生成工具逐镜制作 1～10 分钟、追求「大片感」的叙事短片：奇幻动画、无对白绘本改编、风景史诗或情绪短片。本页专注**故事蓝本、宏观画面语言与短片专属验收**；通用流水线与三态核对见 [生成镜头](generated-shots.md)，5 个导演决定、风格模块、审美诊断与声音分工见 [电影感与视听设计](generated-audiovisual.md)，结构化提示词见 [镜头请求契约](shot-request-template.md)，日式手绘奇幻另读 [日式手绘奇幻风格包](hand-drawn-fantasy-style.md)。对白剧、口播、产品宣传不读本页。

## 1. 先认清单位：一条原片 ≈ 一个镜头

当前常见生成入口单段约 5～10 秒，长片靠逐镜生成后剪辑（以实际入口实测为准）。一条生成片段通常是一个连续机位，从中剪两刀得到的是同机位跳切，不是两个镜头。电影节奏的剪辑镜头多在 3～8 秒：

- 成片镜头数 ≈ 成片秒数 ÷ 平均镜长；4 分钟、平均 5～6 秒约需 40～45 条可用原片。
- 生成次数 = 可用原片 ÷ 实际返回率 + 返修；先用前几条实测返回率，不照抄他人数字。
- 每条原片取动作完整、首尾稳定的一段，入出点各留余量。

## 2. 故事蓝本：改编优先于凭空原创

成熟绘本、童话和民间故事的情节骨架与意象通常比即兴编造更稳。挑选或改编时检查：

| 检查项 | 为什么 |
|---|---|
| 版权：作者去世满 70 年或明确公有领域；在世作者作品只学手法 | 改编要能公开发布 |
| 拍点能用肢体与画面讲清，不靠台词 | 无对白片依赖可见动作；生成工具的对白与画面文字也最不可靠 |
| 世界统一、人物少 | 每多一个反复出现的角色，跨镜一致性风险就增一层；群像最难 |
| 至少 3 个能做成「大景揭示」的时刻 | 大片感主要来自几次空间揭示，而不是镜头数量 |
| 有一个可贯穿全片的道具或强调色 | 让入口、转折与归途有视觉回扣，也方便匹配剪辑 |
| 与知名作品的撞型点 | 入口物件、世界规则、标志性意象与结尾镜头要换掉 |

改编幅度分阶段：初期保留原作骨架，只调人物造型、删恐怖/说教段、补视觉奇观；成熟后再借结构大改。蓝本出处、版权依据、保留与改动写入制作说明。

## 3. 制作顺序：每道关卡过了才花下一笔额度

与 [生成镜头 · 生成流水线](generated-shots.md#生成流水线文件就是记忆) 衔接，叙事短片额外严守四道前置硬关卡：

1. **视觉圣经**：角色定妆、关键场景、段落色彩脚本（主风格 + 可选第二风格模块）经作者认可后锁定。
2. **剧情因果审查**（写完镜头表、出首帧前）：新开审稿者只读镜头表，逐镜复述“观众此刻看到什么、知道什么”，并核四项——① 状态变化有可见过程镜头；② 世界/空间跨越拆成「临界动作 → 穿越过程 → 落地抵达」三拍；③ 道具按可见力源运动，不凭空自移；④ 每镜写明精确人数（防拉远/俯瞰复制角色）。
3. **静图动态分镜（animatic）**：全部首帧按目标时长排进时间线配临时音乐，作者确认故事看得懂、节奏成立后再花视频额度。
4. **动态画风小样（3–5 镜，20–30 秒）**：验证动态画风、运动质感与代表揭示镜，通过后再分段批量生成、粗剪、整片配乐、精剪与连续视听验收。

作者参与节点：视觉圣经、静图版、动态小样、粗剪；中间常规生成与选片由 Agent 完成，不逐镜请示。

## 4. 画面语言：大片感从哪里来

### 大景与尺度
- 人物只占画面约 1～5%，用熟悉人体尺寸衬出空间尺度。
- 每帧前、中、后三层（虚化前景框景、中景主体、远景空气透视）。
- 环境自己在动（云影、草浪、水面碎光、炊烟、飞鸟），大景至少停留 6～8 秒让配乐起势。

### 揭示镜头（全片 3～5 个）
- **拉出揭示**：从手/道具/脸特写缓慢拉开到全景。
- **仰摇揭示**：从地面或背影缓慢上摇到天空或巨构。
- **遮挡揭示**：从门框、井口、树洞或云层后推出去，豁然开朗。
- **俯瞰揭示**：跟随飘落物（羽毛、花瓣、雪）下降，最后俯瞰整片大地。

揭示镜头单独做首帧并优先试片，决定全片上限。

### 运镜与景别节奏
- 运镜动机：推近（情绪靠近）、拉远（揭示/告别）、横移配视差（展示空间）、跟随（旅程）、固定（安静/幽默/凝视）。一镜一路径、慢而稳；高速感用前景掠过、风与布料表现，避免快速甩镜与翻滚。
- 景别交替：全景、中景、特写、触感细节（手接雪、拧布、叩门）形成呼吸；段落按情绪推进色彩脚本，高潮前放慢，结尾回扣开场地点或道具。

### 转场按跳度分级
- 默认直切（靠动作、视线、形状/运动匹配或声音桥衔接）。
- 小跳度用约 0.3 秒短暗转（24fps 约 7 帧，前半渐黑、后半渐亮）；时间流逝用叠化（不用叠化掩盖空间错位）；穿越/梦境可用亮场淡化；大场景或形态跳转才低频使用已登记的特殊转场，同集不相邻重复，写实片不用旋涡等花哨效果。
- 转场两侧必须留真实画面余量，不冻帧、不变速凑时长。

### 特写防漂与无字
- 风格模块与角色锚点（≥2 个不可混淆服装/发饰标识）逐字复用；特写最容易漂画风和五官，须单独核对，必要时挂该角色已认可的特写身份参考。
- 画面不放需要识读的招牌与文字。

## 5. 验收补充

在 [制作流程 · 检查和交付](production.md#5-检查和交付) 与 [生成镜头](generated-shots.md) 之外，额外核对：
- 抽帧数人数（重点查拉远、俯瞰和群景有无角色复制）。
- 连续播放核因果与世界跨越、道具去向、揭示镜头是否真正打开空间且停留足够。
- 核接缝的主体大小、运动方向、光向色温及特写与全景画风一致；整片色彩脚本是否按段落推进。
- 无对白片**关声看一遍**（故事仍看得懂）+ **只听声不看画一遍**（声音段落有起伏、接缝自然）。
