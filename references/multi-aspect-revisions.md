# 多画幅设计与局部反馈

横竖版共享产品事实、素材身份及已认可的声音，分别设计位置和运动。先选目标画幅的作品，再安排镜头；原生竖图不必挤进横版画框，PPT／封面等用途证明仍要给观众看清完整比例的机会。`promotion-selection.md` 的两份 selection 和实际预览可作为最小入口；新画幅不是横版的中心裁切或整画面缩小。

## 按信息选择可复用机制

下列是实现接口示例，坐标、时长和曲线由项目决定。它们是本 Skill 的独立方法描述，不附带其他作者的示范媒体；采用 Lemo 实现时另按 `lemo-opuscar.md` 的固定来源、许可与署名处理。品牌、字体、音乐与照片各保留自己的来源和使用范围。

| 机制 | 解决的信息问题 | 素材前提与画幅处理 |
|---|---|---|
| 音乐段落与作品接力 | 快速让观众认识几种真实成果 | 按音乐实际重音写事件起点；每件有稳定 ID。横版可从并排关系交接，竖版可沿上下方向接力；运动终点给内容稳定阅读窗口 |
| 画风展开 | 从一件清楚作品引出多种视觉选择 | 独立作品只表明丰富度；同题换风格另需来源支持。先保留一张主图，再将后续卡片展为扇形或网格，别用过密缩略图承担文字阅读 |
| 色系切换 | 让观众记住色彩选择 | 同构图换色须真实配对；否则用实际色系选项与各自作品，不通过滤镜伪造生成结果。图像变化、色系短标题、选中状态沿同一事件更新 |

实现时沿唯一时间源取绝对时间，布局函数接收目标画幅和可读区域，不依赖上一帧状态：

```js
const phase = (t, start, end) => Math.max(0, Math.min(1, (t-start)/(end-start)));
const easeOut = u => 1-(1-u)**3;
// Project supplies event times, axis, distance, cards and available region.
const relay = (t, event) => event.distance*(1-easeOut(phase(t,event.start,event.settle)));
const fan = (t, event, index, count) => {
  const u=easeOut(phase(t,event.start,event.settle));
  const unit=count<2?0:index/(count-1)-.5;
  return {offset:unit*event.spread*u, angle:unit*event.angle*u};
};
const currentChoice = (t, changes) => changes.filter(e=>e.start<=t).at(-1) ?? null;
```

项目验证 `end > start`、空组、单图和越界时间；复杂新状态逻辑仍做顺序／逆序／冷启动与接缝检查。这里没有固定 BPM、固定镜头数量或默认调色。声部和许可复用已有锁；动作点变化时更新相应声音事件，不能只把旧音轨机械贴上去。已认可且不受修改影响的音乐可以保留。

安全区先是设计预留：检查标题、品牌、播放器控制条及手机阅读。平台实际界面或真机预览另记，不将项目留白数字称为官方平台规格。

## 版本比较与归因

先明确比较对象，记录在已有制作说明或版本记录中：

| 比较目的 | 共同条件与结论边界 |
|---|---|
| 整体创意 | 可以一起改素材、文字、音乐和剪辑，结论限于这组版本的整体效果 |
| 音乐或某项镜头处理 | 尽量保留其余条件，比较实际相同内容区间；音乐改变导致切点调整时一并说明 |
| 模型独立制作 | 明确共同原始任务、输入材料和自由度；不能因宿主选择同一音源就称为两个模型独立偏好相同 |
| 渲染引擎或实现 | 用相同素材、画幅、代表动作和声音检验输出及可实现性；多变量成片不能证明引擎审美优劣 |

音乐／版本试听可另做响度匹配预览并保留原混音，避免把更响当成更好；测量差异不等于听感差异。整体创意比较不必为控制变量重做全部作品，只有需要验证某个原因时再做有区分力的小对照。看板提供播放与声音切换，不自动成为公平实验或真实听审证据。

## 局部修改的影响范围

先绑定当前版本、时间与对象，写明“改什么、保留什么、哪些边界受影响”。例如角标尺寸变化可以只改相关段落的布局与绘制；不重新选图、改开篇音乐或重开风格讨论。能可靠分段时重建受影响片段，否则可完整编码，但创意和选择保持已定结果。

保留旧版，音轨没变可直接复制；输出到新版本并绑定新文件回执。检查修改对象、进入与退出边界，以及明确保留的结尾等位置。布局相同可对指定帧／区域比较；有损编码差异不能自动当成内容变化。压缩音频包相同证明音轨未换，不代表新版正式验收自动通过；历史声音反馈与当前 HTML 绑定限制按 [主流程](production.md#5-检查和交付) 分开保留。

项目可记录一次缩小比例、原话反馈、源文件／媒体 hash 与同位置前后图；比例不成为全局品牌默认。旧版认可只在明确保留的范围复用，不自动成为新版整片用户认可。方法与工具测试、真实观看、用户采用和平台上传分别记录。
