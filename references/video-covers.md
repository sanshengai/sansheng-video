# 视频封面与首帧

适用短、中、长视频的封面设计，以及旧视频换封面。新作在前期同时考虑封面；局部改声音等无关任务不自动重做已认可封面。封面负责让观众愿意点开，开场负责兑现内容，两者都不能用模板占位图冒充最终画面。

## 先选画面，再安排信息

从本片实际画面或已授权素材中挑一幅有吸引力、与本集相关的图，优先人物表情、动作关系和能代表主题的场景。同系列保留字体、层级与识别方式，每集更换有内容依据的背景；不要把整季做成同一底图换字。生成新的封面画作须走宿主图像工具，不能默默改写角色、史实或产品成果。

默认可从“真实画面＋左上磨砂标题条”开始：较小的系列名、清楚的集名、季集编号集中在左上。短标题用一行，长标题调整条宽、字号或行数，以缩略图可读为准。烟蓝半透明底、背景模糊、细亮边、小圆角与克制阴影能分开白字和复杂背景；浅底改用深字。参数服从实图，不能只有透明度、没有可读性。

这是可调整的视觉起点。作者或项目已有选定样式时沿用；历史、人文、课程、产品宣传各自的材质、字体和色彩仍服从其内容与品牌，不能因用同一工艺就全变成动漫海报。审美尚未确定时，Agent 先推荐少量差异明确、使用真实素材的方案；作者选中后记录并复用，不重开海量模板筛选。

## 横竖版分别构图

同一内容不等于同一裁切。竖版可聚焦主角，横版尽量保留人物关系和动作，标题条按横屏缩短、减高，给画面留空间；不要横向拉伸竖版，也不要让玻璃条为铺满屏幕而遮脸。横竖版都检查人脸、手势、道具、关键文字与平台界面预留区域。项目留白只是设计值，平台实际裁切须在上传界面再核。

先交一组实际横竖版对照，再把相同规则扩到全系列。显示尺寸、照片来源、裁切与文字都应可追溯。按小缩略图和完整尺寸各看一次；长集名、浅亮背景与人物靠上是优先检查的反例。设计阶段发现信息放不下，应改布局或换图，不把字缩到失去作用。

## 嵌入首帧时保留原时间线

若项目采用首帧封面，可停留约 0.4 秒后进入正文；这是可调项目值，不是平台规定。已有片头是否替换，先读真实装配时间线并核对最终文件。只有明确识别且授权替换的品牌引子才能删；不猜每部视频都从 3.6 秒开始，更不裁掉开场对白。已经直接进入故事的片子可在前面加封面，不动正文。

画面与声音沿同一时间偏移，保留正文配音、音乐、音效及片尾。首帧停留可留白或沿项目开场设计，不另加一段抢戏的音乐。边界有语音、动作或音尾时单独处理，不能靠笼统淡入掩盖被截断的问题。输出到新版本，原文件和原校验值保留。

## 批量与交付

批量开始前，用季集台账、当前成片回执和实际文件绑定“内容 ID／展示季集号／画幅／版本／来源校验值／封面画面／时间偏移”。公开 ID 与制作 ID 可能从不同数字起算，必须机器比对；不按文件名里的最大版本号、修改时间或目录中随便一条视频猜最终版。没有成片的集数列为待补，不用旧稿顶替。

交付同版 MP4、独立封面图和可编辑布局。逐条检查文字未溢出、画幅正确、首帧出现、切入点对齐、时长符合偏移、音画共同移动与完整解码；设计复核不等于整片人工接受。旧版已认可的声音只有未受影响的范围可沿用，技术通过不能代作者批准。

交给分发端时明确该版本已嵌首帧，并携带同版封面图与校验值。平台未必默认取第一帧；实际上传后核对预览，必要时选第 0 秒或上传独立图，不能为了省一次操作接受错误封面。不要让分发端重新选择画面、重做设计或再次编码。封面制作不自动授权修改已发布作品。
