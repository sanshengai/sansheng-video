# 镜头与视觉机制

按表达目的选机制，不按库存轮换风格。以下是制作方法，不是预制大片模板或上游效果复刻承诺。

| 表达问题 | 可采用机制 | 执行要点 |
|---|---|---|
| 对象关系、系统、流程 | 连续空间、追踪路径、逐步展开 | 先让关系可辨认，再用运动展示变化；主对象和相机坐标一致 |
| 概念变化与对比 | 图形形变、拆合、遮罩、对应映射 | 形变前后保留身份；同一概念使用一致形状和颜色；变化本身承载意义 |
| 推导、解释、教学 | 手绘推理、分步出现、标注跟随 | 笔画完成后留理解时间；不要用一直抖动干扰阅读；声音锚点未知用句级 |
| 人文、历史、观点 | 印刷材质、固定纸纹、网点与克制排版 | 纹理固定种子，不逐帧随机；真实档案标来源，不把生成图当证据 |
| 大场景和尺度 | 前中后景、层次、镜头路径、视差 | 先构图后运动，避免无意义缩放；专用 3D 或透明媒体输出按实际工具能力确认 |
| 中文重点 | 词句锚点、局部强调、阅读窗口 | 不缺字，不把整段压成无法读完的小字；安全区按实际画幅与播放器检查 |

动画按时间求值，弹簧、缓动、噪声均应可 seek。阶段动作采用起势、变化、收束、稳定期；不把所有运动统一成同一种入场。相机与物体分层，避免父子 transform 重复；字体和材质支持视觉主线，不能盖过内容。

选择一个主机制和少量辅助机制即可。全片一致并不等于所有镜头一样；章节之间优先靠对象与意义衔接，确需转场才加。复杂度与阅读冲突时先保证观众理解。

横竖画幅按信息关系分别布局，不能仅缩放或裁掉横版。专业 3D、人物表演和生成视频不能由简单代码图形冒充；保留现有工程或用户授权工具，无法执行时明说边界。

需要具体术语、动态样例或实现参数时，按 [动效与音效](motion-and-sound.md) 查 Motion Prompt；只取当前镜头需要的条目，适配项目语言和风格。
