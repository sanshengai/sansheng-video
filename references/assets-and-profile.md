# 素材、品牌与私有配置

## 先核镜头适用性

从原镜头的目的、需要看见的行为／关系、运动、裁切与事实要求判断素材是否适用，再按下列顺序找来源。已有且有许可只是可复用，不是必须使用；水面、房间或背影可以承担氛围，未必能让观众看见听歌、交流或行动。需要具体行为时优先检查画面本身是否表达，不靠字幕把不相符素材解释成正确。

静图适合停留、细节和可明确设计的图形变化；代码适合关系与可控动作；真实或生成片段适合主体行为及环境持续变化。按当前镜头选用，既不强制每片加入真实视频，也不为省取材将静图推拉当作所有动作的替代。生成主体的运动仍按 [生成镜头](generated-shots.md) 验证，不能靠相机移动冒称发生了行为。

## 默认来源

1. 当前项目已有且许可明确的素材。
2. 若当前 profile 显式启用用户选定的 `media_library`，读取其 `usage`，用配置提供的工具按当前镜头需求检索；适合才取项目副本与来源回执。不因库中存在文件就采用，也不把检索结果当作已经入片。
3. 未配置精选库或确认库中缺件时，新音效走 [Openverse](openverse-sfx.md)，运动设计走 [动效与音效](motion-and-sound.md)。
4. 真实通用 B-roll 缺件时走 [在线画面素材](stock-footage.md)；解释图与概念画面优先代码或生成。

推荐为空时，按库工具的词表、筛选条件和批准区间核对原因，区分库中没有与当前镜头不适用。关键词搜到文件只证明存在；事件窗口、尾音、对白或许可不合时仍不能采用。需要短段时先试听并记录实际可用区间，不靠硬截尾音或放宽条件使候选入选。

新配乐在项目／精选库缺件后，沿宿主已有授权的检索或音乐工具找来源，核对实际乐段、许可和试听条件；本包没有统一的在线配乐服务。Openverse 音效下载流程不等于已经实现配乐检索或原创作曲。工具不可用时说明缺项或交付待选声音的候选，不偷偷安装、付费或以合成音床冒充选好的音乐。

退休的本机全量库、网盘冷库及其目录扫描、入库／回填、推荐与定时维护不再进入视频生产；失败时也不回退到旧库。用户通过当前 profile 显式启用的精选库按上面的来源顺序使用，不恢复退休服务。百度网盘作为通用资料读取工具独立保留，取论文、文稿等资料不触发素材库流程。项目内已采用的文件和配音模型缓存属于工程依赖，按原工程继续使用。

每个缺件先描述镜头作用、情绪、能量、时长、画幅和事实要求。每轮最多 3 个候选、最多两轮词；选中才下载，找不到就改画面方案。仅保留项目采用文件和短期网络缓存，不编目全站、不自动同步网盘、不新建中央库。

在项目 sources.json 或现有素材锁中记录来源页、作者、许可／授权依据、用途、本地相对路径和 SHA256。下载权限不等于公开商用权。品牌标识使用原文件。

## 品牌配置

完整标识与独立图形按用途选择原件，深底变体不等于一律全白。可选 `brand.variants` 及横竖屏 alpha 可见边界预览见 [品牌工具](promotion-evidence.md#品牌原件与横竖屏预览)，旧 `logo` / `logo_on_dark` 仍可使用。Logo 尺寸反馈属于当前项目，不自动写成所有视频的默认值。

显式设置 SANSHENG_VIDEO_PROFILE_DIR 时读取该目录 profile.json；否则只识别用户主动建立的仓根 profile/（可为链接）。运行 `python3 setup.py --show-profile` 获取真实配置与根目录。配置错误明确报错，不默默改品牌。

推荐字段见 profile.example/profile.json：brand、content_rules、output_root、legacy_root。可选 `media_library` 由用户显式配置 `root`、`tool` 和 `usage`；相对路径按 profile 根解析，不假定本机目录或工具接口。未启用时继续项目与在线来源，不要求建设素材库。legacy_root 仅用于已有生成执行器等私有能力，不是素材目录。旧配置中的 asset_roots、cold_storage_root 被忽略且不向 Agent 暴露。资源相对 profile 解析；交付只复制实际采用且有权使用的文件。profile 不保存密钥。
