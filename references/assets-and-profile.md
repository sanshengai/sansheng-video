# 素材、品牌与私有配置

## 默认来源顺序

1. 项目已有且可采用的素材。
2. 新增或替换音效，按镜头动作与情绪优先走 [Openverse 音效流程](openverse-sfx.md)，选中才下载到当前工程。
3. 其他素材按用途检索公开资源、使用合适的精品件或生成概念素材。
4. 本地音效库与网盘冷库只作明确指定或在线缺件时的补充，不作为新音效的默认检索前置。不要求先建库、扫库或上传归档才能制片。

每次寻找先描述用途、情绪、能量、时长、画幅和证据要求，避免只按同名文件命中。试听过的声音还要在当前片中判断，不因为叫“高级转场”就采用。普通转场优先代码；不额外建立大型素材检索平台。

在项目 `sources.json` 或现有素材锁中记录实际采用的来源页、作者、许可证／授权依据、用途、本地相对路径和 SHA256。用户能访问文件与拥有公开商用权是两回事。真实品牌标识从品牌原文件取，不让模型重画。

## 品牌与本机资源

显式设置 `SANSHENG_VIDEO_PROFILE_DIR` 时读取该目录 `profile.json`；未设置时只识别用户主动建立的仓根 `profile/`（可为链接）。两者都没有时无需私有配置。运行 `python3 setup.py --show-profile` 获取真实配置与根目录；配置缺失或格式错误应明确报错，不默默退回另一个品牌。

推荐字段见 `profile.example/profile.json`：brand（名称、颜色、logo、字体说明）、content_rules（角色与栏目资料路径）、output_root、asset_roots、legacy_root。所有这些只是本机输入，不改变公共核心。资源相对 profile 目录解析；发布或交付工程时再复制确有许可的必要资源。

profile 不保存密钥。第三方服务凭证只由宿主已配置的工具处理；本包没有默认生成／搜索／上传账户。冷库管理和私有内容技能可以通过 profile 指路，不进入公开分发。

小精品库先保持目录加清单即可。声音未实际试听就标待试听；字体不捆绑则记录获取方式与许可。不要为了凑数量整理大量素材。
